A / D — 左右移动
空格 — 跳跃
左Shift —  冲刺
J — 攻击
K — 格挡 在敌人攻击前
B — 打开技能面板

可以在空中冲刺
可以附着在墙上并且缓速下降

数值系统
Strength 力量	_物理伤害	damage + strength
Strength 力量	_暴击伤害	critPower + strength * 0.5%
Agility 敏捷	_暴击率	critChance + agility * 0.3%
Agility 敏捷	_闪避率	evasion + agility * 0.5%，上限 85%
Intelligence 智力	_元素伤害	最高元素伤害 + 其他元素伤害 * 50% + intelligence
Intelligence 智力	_元素抗性	对应抗性 + intelligence * 0.5%，上限 75%
Vitality 活力	最大生命	_maxHealth + vitality * 5
Vitality 活力	护甲	_armor + vitality

元素效果按照最高元素伤害结算
Ice  缓速
Fire 持续性的伤害
LightningStrike 累计条满之后造成大量伤害
